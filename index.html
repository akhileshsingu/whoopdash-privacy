Privacy Policy — Whoop Dashboard

Last updated: October 2026

This is a personal, non-commercial project for visualizing my own WHOOP fitness data. It is not distributed to the public.

Data Collection

This application accesses WHOOP account data (recovery, sleep, workout, and cycle data) via the WHOOP API, using OAuth 2.0 authorization granted by the account holder.

Data Use

Data is used solely to display fitness analytics within this application. It is not sold, shared, or used for any purpose other than the account holder's own personal dashboard.

Data Storage

Data is stored locally in an H2 database for the duration of the application's use and is not transmitted to any third party.

Revoking Access

Access can be revoked at any time via WHOOP account settings, or by contacting the app owner below.
